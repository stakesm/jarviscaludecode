# HORZ MOBILE: сверка карты (модели IPL против архива)

Источник: `HORZ_MOBILE_mapkit.zip` (763 МБ, 107 файлов), разобран на VPS в `/srv/blender/mapkit/`.
Сами паки моделей и текстур сюда не входят: это ассеты Black Russia.

| Файл | Что это |
|---|---|
| `models_audit.csv` | Все 9 083 модели из подключённых в `config.dat` IPL: id, модель, txd, IDE, статус, пак, наличие коллизии, число размещений и в каких IPL. Разделитель `;`, кодировка UTF-8 (открывается в Excel). |

| `blender_scripts/` | Скрипты, которыми всё посчитано (запускаются в Blender на VPS, пути `/srv/blender/mapkit/...`). |
| `horz_map_audit.zip` | Всё перечисленное одним архивом. |

## Методика

1. Берутся только IPL и IDE, подключённые в `maps/data/config.dat` (все они есть в архиве).
2. Для каждой строки `inst` номер модели ищется в IDE, имя модели сверяется с файлами `.mod`
   в `br_map_00/01/02.bpc` (19 841 файл) и с именами в коллизиях `br_collision.bpc`.
3. Отсутствующие проверены на различия в регистре и суффиксы `_2`, `_3`: похожее имя только у `SM_flg_Pplr_A`.

## Форматы

- **Модели `.mod`**: собственный недокументированный формат, у всех файлов заголовок `331092ab`.
  Ни README, ни `bpc_tools.py`, ни DragonFF его не читают. Средняя энтропия 4,4–5,5 бит/байт, то есть
  шифрование не подтверждено. Открыть их можно только разбором формата, этого не делалось.
- **Текстуры `.btx`**: KTX1 с 4-байтным префиксом (описано в `tools/README.md`), ASTC 6×6 / RGBA8 / RGB565.
  В архиве 601 (`br_tex_txd`) + 1 666 (интерьеры) + 206 тайлов радара. Для PNG нужен `astcenc`
  или отсутствующий в архиве `dec_btx.py`.
- **Коллизии `.cls`**: читаемый формат (`CLST` + имя + `CED2`), из них взяты габариты для плана.

## Чего не хватает для полного вида карты в Blender

1. Документированный конвертер или спецификация `.mod` либо модели в DFF/OBJ/FBX.
2. Шесть паков из списка выше.
3. Основные текстуры города: в `br_tex_txd` всего 4,7 МБ.
4. Связка модель → текстура (внутри `.mod`).
5. `dec_btx.py` / `astcenc`.
6. Для вида «как в игре»: таймцикл, вода, небо.
